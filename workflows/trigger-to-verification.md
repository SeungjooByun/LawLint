`rules/triggers.md`가 "언제 멈출지"를 정의한다면, 이 문서는 "멈춘 다음 뭘 할지"를 정의한다. SKILL.md는 이 절차를 그대로 따른다.

## 단계

1. **감지**: 지금 보고 있거나 작성 중인 코드가 `rules/triggers.md`의 47개 항목 중 하나 이상과 패턴이 겹치는지 확인한다. 대부분은 "이 코드가 보이면 걸림"(존재-탐지)이지만, 1·16·35·36·37번처럼 "있어야 할 게 안 보이면 걸림"(부재-탐지)인 경우도 있다 — 실제 오픈소스 재현율 테스트에서 부재형이 오히려 제일 흔했다([examples/](../examples/) repro-test-*.md 6개). 회원가입/사용자 엔티티·DTO·업로드 코드를 볼 때는 "무엇이 있는지"뿐 아니라 "무엇이 빠져 있는지"도 확인한다.
   - **오탐 방지(29~34번 세무 트리거 한정)**: 결제 연동이 `MockPgClient`, 테스트 API 키처럼 명백히 모의/학습용이면 발동하지 않는다. 실제 운영 키가 보일 때만 발동한다.
   - **오탐 방지(8번 한정)**: "AI 챗봇이 있다"만으로 걸지 않는다 — RAG(관리자 문서 검색)와 "사용자 대화를 학습에 재사용"은 다르다.
   - **오탐 방지(12번 한정)**: "구독(subscribe)"이라는 단어만 보고 걸지 않는다 — SNS 팔로우 기능(가격·결제주기 필드 없음)과 유료 정기결제는 다르다.
2. **후보 확정**: 겹치는 트리거 번호와 관련 법령명(트리거 파일에 이미 적힌 것)을 특정한다. 겹치는 게 없으면 아무 말도 하지 않는다.
3. **검증 호출** (아래 우선순위, 하나가 성공하면 중단):
   1. **law.go.kr 직접 조회 (기본 경로)** — 아래 "law.go.kr 원문 확인 방법" 절차를 따른다. 설치·가입 없이 바로 쓸 수 있고, 정부가 직접 운영하는 유일한 경로라 가장 신뢰할 수 있다.
   2. **beopsuny 스킬** (설치되어 있는 경우만) — 필수 의존성이 아니라 선택적 보강. law.go.kr로 이미 확인했으면 다시 부르지 않는다.
   3. **korean-law-mcp** — 기본 경로로 채택하지 않음(아래 "왜 law.go.kr을 기본으로 정했는가" 참고). OC 코드가 이미 설정돼 있는 예외적인 경우에만 헌재·행정심판·조례처럼 law.go.kr 일반 검색으로 안 되는 영역에 보조로 쓴다.

4. **라벨링**: `rules/uncertainty.md` 기준으로 `[VERIFIED]/[UNVERIFIED]/[INSUFFICIENT]` 라벨을 붙인다. 47번(규제 공백형)처럼 "위반 여부"가 아니라 "아직 규제가 없다"는 걸 확인한 경우는 이 3라벨 체계로 다 표현이 안 된다 — 별도 정의 필요(미해결).
5. **출력**: `templates/legal-review-report.md` 형식으로 짧게 정리해서 보여준다.

## law.go.kr 원문 확인 방법 (2026-09-17 확정)

**문제**: law.go.kr은 최근 UI가 자바스크립트로 내용을 그리는 SPA라, 자바스크립트를 실행하지 않는 단순 HTTP 요청(WebFetch 등)으로는 제목만 있는 빈 껍데기를 받는다. "예쁜 URL"(`/법령/개인정보보호법/제30조`)도 마찬가지다.

**해결**: 실제 브라우저처럼 페이지를 렌더링하는 도구(Claude Code Browser 도구의 `navigate` + `get_page_text`)로 열면 조문 전문이 그대로 나온다. 실측으로 개인정보보호법 전체 조문(제1조~제76조)을 이 방법으로 받았고, 그 안에서 8번 트리거의 AI 특례 조문(제28조의12, 2027-3-9 시행)이 실제 법 원문에 포함된 것도 1차 소스로 재확인했다.

**절차**:
1. `https://www.law.go.kr/법령/{법령명}/제{N}조` 같은 예쁜 URL을 브라우저로 먼저 연다 — lsiSeq를 알아내기 위한 단계(네트워크 요청 로그에서 `lsiSeq=` 값 확인)
2. `https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq={lsiSeq}&joNo={4자리 조번호}&joBrNo=00&docCls=jo&urlMode=lsScJoRltInfoR`를 브라우저로 연다
3. **주의**: 이 URL은 조문 하나가 아니라 **법령 전체 본문**을 반환한다 — 필요한 조문을 텍스트에서 검색해서 찾는다
4. `get_page_text`로 렌더링된 텍스트를 가져와 확인한다

## 왜 law.go.kr을 기본으로 정했는가 (korean-law-mcp/법망 API 대신)

korean-law-mcp와 법망 API는 둘 다 **제3자가 운영하는 중계 서버**(각각 `fly.dev`, 개인 재능기부)를 거친다 — 검색어(=LawLint가 무슨 코드를 보고 있는지에 대한 힌트)가 낯선 개인 서버 로그에 남을 수 있고, 가용성 보장도 없다(법망 API는 실제로 503 확인됨). law.go.kr은 정부가 직접 운영하는 유일한 경로라 이 두 문제에서 자유롭다. OC 코드 발급(정부 사이트 가입) 같은 추가 설치 부담도 없다. 단점은 결과가 법령 전체 본문이라 필요한 조문을 텍스트에서 다시 찾아야 한다는 것뿐 — 감수할 만하다.

korean-law-mcp는 완전히 배제하지 않고, law.go.kr 일반 검색으로 안 되는 영역(헌재 결정, 행정심판, 조례)에서 OC 코드가 이미 있는 경우에만 보조로 쓰는 선택지로 남겨둔다.
